# If when running script files in Linux the system outputs a message like this: `"bash: ./script_name: cannot execute: required file not found"` — run the following command on each script: `dos2unix script_name`, or: `find . -maxdepth 1 ! -name "install_zapret-discord-youtube.ps1" -type f -exec dos2unix {} +`

# To convert back to DOS format, run the following command: `find . -maxdepth 1 ! -name "install_zapret-discord-youtube.ps1" -type f -exec unix2dos {} +`
